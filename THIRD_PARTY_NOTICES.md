# Лицензии третьих сторон

Xerox Zine Studio использует следующие открытые компоненты. Все они распространяются
вместе с программой на условиях своих лицензий.

| Компонент | Лицензия | Сайт |
|---|---|---|
| Python | PSF License Version 2 | https://www.python.org/psf/license/ |
| Tcl/Tk | Tcl/Tk License (BSD-подобная) | https://www.tcl.tk/software/tcltk/license.html |
| Pillow | MIT-CMU (HPND) | https://github.com/python-pillow/Pillow/blob/main/LICENSE |
| NumPy | BSD 3-Clause | https://numpy.org/doc/stable/license.html |
| OpenCV (opencv-python-headless) | Apache License 2.0 | https://github.com/opencv/opencv/blob/4.x/LICENSE |
| tkinterdnd2 | MIT | https://github.com/pmgagne/tkinterdnd2 |
| tkdnd (внутри tkinterdnd2) | BSD-подобная | https://github.com/petasis/tkdnd |
| PyInstaller (только сборка; загрузчик входит в exe) | GPL 2.0 с исключением для сборок | https://github.com/pyinstaller/pyinstaller/blob/develop/COPYING.txt |

Шрифты в программу не входят: используются шрифты, установленные в Windows.
